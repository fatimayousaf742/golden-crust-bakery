# 🚢 Titanic Survival Prediction System

A full-stack machine learning application built to predict passenger survival probability on the Titanic dataset using Logistic Regression, FastAPI, and React.

---

## 📌 Features

* **Machine Learning Model**: Logistic Regression trained on preprocessed Titanic passenger features.
* **REST API Backend**: FastAPI service handling real-time prediction requests with data validation.
* **Interactive Dashboard**: Modern React single-page frontend with responsive input forms and live survival probability displays.
* **CORS Configured**: Configured for cross-origin resource sharing between local frontend and backend services.

---

## 🛠️ Tech Stack

* **Frontend**: React, Vite, CSS3
* **Backend**: Python 3.12, FastAPI, Uvicorn
* **Machine Learning**: scikit-learn, pandas, numpy, joblib
* **Version Control**: Git, GitHub
